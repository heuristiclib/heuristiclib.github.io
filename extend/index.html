Extend HeuristicLib ​

These pages show how to write your own operators, operations, algorithms, wrappers and analyzers. Most applications need none of them. Configure and compose built-in components first, and put domain evaluation in a problem.

Your components work like built-in ones. They are validated, observed and run the same way.
