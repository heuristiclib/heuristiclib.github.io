Operators by encoding ​

The operators of the core package, grouped by the candidate they work on. Operators explains the roles, and Operator composition covers the operators that combine others.

Real vectors ​

Candidate RealVector, search space BoundedRealVectorSearchSpace.

OperatorRoleDoes
UniformDistributedCreatorCreatorDraws each element uniformly within the bounds
NormalDistributedCreatorCreatorDraws each element from a normal distribution, clamped to the bounds
AlphaBetaBlendCrossoverCrossoverSamples each element around both parents, wider towards the better one
SimulatedBinaryCrossoverCrossoverSimulated binary crossover (SBX)
SelfAdaptiveSimulatedBinaryCrossoverCrossoverThe self-adaptive variant of SBX
SinglePointCrossoverCrossoverJoins the head of one parent with the tail of the other
GaussianMutatorMutatorAdds normal noise to each element with a given rate and strength
PolynomialMutatorMutatorPolynomial mutation, clamped to the bounds

Integer vectors ​

Candidate IntegerVector, search space IntegerVectorSearchSpace. The rounded operators compute a real value and round it into the bounds.

OperatorRoleDoes
UniformDistributedCreatorCreatorDraws each element uniformly within the bounds
NormalDistributedCreatorCreatorDraws each element from a rounded normal distribution
DiscreteCrossoverCrossoverTakes each element from a randomly chosen parent
SinglePointCrossoverCrossoverJoins the head of one parent with the tail of the other
RoundedAverageCrossoverCrossoverAverages the parents
RoundedBlendAlphaCrossoverCrossoverSamples each element from the parents' range, widened by Alpha
RoundedBlendAlphaBetaCrossoverCrossoverLike blend alpha, widened by Alpha and Beta
RoundedHeuristicCrossoverCrossoverSteps from the worse parent past the better one
RoundedLocalCrossoverCrossoverA random weighted average per element
RoundedUniformArithmeticCrossoverCrossoverA weighted average at positions chosen with Probability
UniformOnePositionMutatorMutatorReplaces one element with a uniform value
UniformSomePositionsMutatorMutatorReplaces each element with probability Probability
RoundedNormalOnePositionMutatorMutatorAdds rounded normal noise to one element
RoundedNormalAllPositionsMutatorMutatorAdds rounded normal noise to every element

Bool vectors ​

Candidate BoolVector, search space BoolVectorSearchSpace or FixedCardinalityBoolVectorSearchSpace.

OperatorRoleDoes
RandomBoolVectorCreatorCreatorSets each element with probability SetProbability
BitUniformCrossoverCrossoverTakes each element from a randomly chosen parent
BitFlipMutatorMutatorFlips each element with probability FlipProbability
BitSwapMutatorMutatorSwaps one set and one cleared element, so the count of set elements stays

Permutations ​

Candidate Permutation, search space PermutationSearchSpace.

OperatorRoleDoes
RandomPermutationCreatorCreatorDraws a uniformly random permutation
OrderCrossoverCrossoverKeeps a segment of one parent, fills the rest in the other's order
EdgeRecombinationCrossoverCrossoverBuilds the child from edges both parents contain
SwapMutatorMutatorSwaps two elements
InversionMutatorMutatorReverses a segment

Expression trees ​

Candidate ExpressionTree, search space ExpressionTreeSearchSpace. Symbolic expressions and Symbolic regression explain the settings and the numeric perturbations.

OperatorRoleDoes
GrowTreeCreatorCreatorGrows trees of mixed shape up to MaximumDepth
FullTreeCreatorCreatorBuilds trees whose leaves all sit at Depth
RampedHalfAndHalfTreeCreatorCreatorMixes grow and full trees over a range of depths
BalancedTreeCreatorCreatorBuilds trees of a requested length breadth-first
ProbabilisticTreeCreatorCreatorProbabilistic tree creation (PTC2) for a requested length
SubtreeCrossoverCrossoverReplaces a subtree of one parent with a subtree of the other
SubtreeMutatorMutatorReplaces a random subtree with a newly grown one
ShrinkSubtreeMutatorMutatorReplaces an operation with a terminal
NodeReplacementMutatorMutatorReplaces one symbol with another of the same arity
LocalPerturbationMutatorMutatorPerturbs constants and variable weights
NumericParameterFittingRefinerRefinerFits the numeric parameters of a symbolic regression model

Any candidate ​

These operators work for every candidate type.

Selectors ​

OperatorDoes
TournamentSelectorPicks the best of TournamentSize random candidates
ProportionalSelectorPicks in proportion to quality
LinearRankSelectorPicks in proportion to rank
GeneralizedRankSelectorPicks by rank with a configurable Pressure
RandomSelectorPicks uniformly
BestSelectorPicks the best candidates
WorstSelectorPicks the worst candidates
ParetoCrowdingTournamentSelectorTournament by Pareto rank, then crowding distance
EliteSelectorTakes the best Elites, then asks another selector for the rest
NoSameMatesSelectorAsks another selector again when both parents are the same
GenderSpecificSelectorPairs one candidate from each of two selectors

Replacers ​

OperatorDoes
ElitismReplacerKeeps the best Elites of the previous population
PlusSelectionReplacerKeeps the best of parents and offspring together
CommaSelectionReplacerKeeps the best offspring only
