Analyzers and traces ​

The analysis building blocks of the core package. Analysis of algorithm runs shows how to place them and read their results.

Observation sources ​

A source names a boundary to observe. Creating one installs nothing.

SourceObservesObservation
operator.InvocationsEach successful call of the operatorThe operation's record, such as MutationObservation<T>
algorithm.IterationsEach state the algorithm yields, after interceptorsAlgorithmObservation<T, TState>
algorithm.CallsThe start and outcome of each executor callAlgorithmCallObservation<T, TState>

Every operation offers Invocations, including operations you define.

Analyzers ​

Pass an analyzer to CreateRun and read its result with run.Result(analyzer).

AnalyzerRecordsResult
Analyzer.BestSoFar<T>()The running best candidate at the innermost evaluatorsBestSoFarCurve<T>
Analyzer.BestSoFar(evaluator)The running best candidate at one evaluatorBestSoFarCurve<T>
algorithm.Iterations.TracePopulationQuality()Best, median and worst objective vector of each yielded populationTrace<BestMedianWorst>
algorithm.Iterations.TracePopulationCandidates()Best, median and worst candidate of each yielded populationTrace<BestMedianWorstEntry<T>>
source.Trace(value) or Analyzer.Trace(sources, value)One value per observationTrace<TValue>
source.Aggregate(create, update) or Analyzer.Aggregate(sources, create, update)One state updated by every observationThe state you create

Each trace and best-so-far analyzer takes optional clocks and retention arguments. A best-so-far curve point carries its Evaluations, Value and Candidate. A trace offers SampleCount, Latest, Snapshot() and By(clock).

Clocks ​

A clock gives each recorded entry its time. Pass clocks in the clocks argument of a trace.

ClockReads
counter.ClockThe count of a Counter
duration.ClockThe time of a Duration
Clock.ElapsedThe time the run spends advancing its algorithm

Counting and timing ​

Counters and durations record nothing until a placement updates them. Pass the placement to CreateRun or Substitute, after the analyzers that read it.

PlacementUpdates
source.Counting(counter)Counts the observations of a source
source.CountingCandidates(counter)Counts the candidates of an operator's calls
source.Timing(duration)Adds the time of an operator's calls
algorithm.Timed(duration)Adds the time of an algorithm's calls
source.Observing(callback)Passes each observation to a callback

Retention ​

Retention decides which computed values a trace keeps.

RetentionKeeps
TraceRetention.EveryObservation()Every value, the default for traces
TraceRetention.OnChange()A value that differs from the previous one, the default for best-so-far
TraceRetention.EveryNth(n)Every n-th value
TraceRetention.LatestOnly()Only the latest value
